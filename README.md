# Cooksy Flip-Card Webpage

A flip-card style Cooksy webpage showing each dish with its name, image, and recipe in an interactive one-page layout.

## Features
- Interactive flip-card design  
- Front side: Dish name + Image  
- Back side: Recipe  
- Clean and responsive layout  
- Beginner-friendly HTML, CSS, JavaScript project  

## Technologies Used
- HTML  
- CSS  
- JavaScript
- Github-Pages

## How to Use
1. Clone the repository  
2. Open `index.html` in any browser  
3. click on a card to view the recipe
